# 용어집 (영문 시안 → 한글 표기 확정)

> 스토리보드의 영문 캡처는 참고용이며 **실제 화면은 전부 한글**로 제작한다.
> 여기서 정한 표기를 전 화면에서 동일하게 쓴다. 새 용어가 나오면 여기에 먼저 추가한 뒤 화면에 반영한다.

## 표기 원칙

- **에코바디스**는 한글 표기를 기본으로 하되, 평가 문항 코드(ENV 1.1, LAB 3.1 등)는 원문 유지 — 실제 평가지가 그 코드를 쓴다.
- 파일 확장자(PDF, XLSX, MD, HWP), 기술 용어 중 업계 표준어(OCR, RAG, AI, ESG, ISO)는 영문 그대로 둔다.
- 데이터 식별자(`org_01H_AMBER`, `ESG-2026-EVAL`)는 시스템 값이라 영문 유지.
- 숫자 + 단위는 붙여 쓴다: `1,284건`, `24.8MB`, `84페이지`.
