# 산출물 명세서 — Amber Document Intelligence 프론트엔드 목업

> 대상: 클라이언트(검수·인수) · 후속 개발자
> 기준: 「Amber UIX 설계서 V0.1 (2026.07.19)」 63쪽 + 시안 `dc.html`
> 범위: **DB·백엔드 없는 프론트엔드 목업**. 화면·인터랙션·데이터 흐름은 실제로 동작합니다.

---

## 1. 무엇을 받는가

| 구분 | 내용 |
|---|---|
| **실행 가능한 앱** | React 19 + Vite 프로젝트 소스 일체. `npm install && npm run dev` 로 바로 실행 |
| **정적 빌드본** | `npm run build` 결과물(`dist/`). 웹서버에 그대로 올리면 동작 |
| **화면** | 10개 화면 + 26종 레이어(모달·시트) — 설계서 63쪽 대비 **116항목** 구현 |
| **실제 문서 12종** | 목업이 아닌 **진짜 PDF·XLSX·DOCX 파일**. 문서 보기에서 실제로 렌더·페이지 이동·확대축소 |
| **문서 4종** | 산출물 명세서(본 문서) · 품질 검증 보고서 · 개발자 가이드 · 용어집 |
| **검수 도구** | 작업목록(116항목 인덱스) + 플로팅 검수 바 + 해시 딥링크 |

### 포함되지 않는 것 (계약 범위 외)
- 백엔드 API · 데이터베이스 · 실제 인증
- 실제 AI 모델 호출(OCR·RAG·챗봇 응답은 **시뮬레이션 연출**)
- 파일 실제 업로드/저장 (브라우저 메모리에만 반영, 새로고침 시 초기화)

## 2. 실행 방법

```bash
npm install          # 의존성 설치 (최초 1회)
npm run dev          # 개발 서버 → http://localhost:5373
npm run build        # 정적 빌드 → dist/
npm run preview      # 빌드본 미리보기
npm run lint         # oxlint 정적 검사
```

**Node 20 이상** 권장. 별도 환경변수·API 키 없음.

### 클라이언트 검수 동선
1. `http://localhost:5373/` 접속 → **로그인 화면**(아무 값이나 입력해도 통과)
2. 로그인 → **작업 목록**(설계서 대비 제작 현황 116항목) 착지
3. 각 행의 **[열기]** → 해당 화면·모달·시트가 **그 상태 그대로** 열림
4. 우하단 **검수 바** `‹ ›` 로 순서대로 이동
5. 헤더 우측 **[작업 목록]** 으로 언제든 복귀

## 8. 인수인계 시 알아야 할 규칙

1. **페이지를 늘리지 않는다** — 새 화면은 라우트가 아니라 `ScreenKey` 추가
2. **아이콘은 Material Symbols만** — `<Icon name="folder" />`
3. **네이티브 `<select>` 금지** — `components/common/select.tsx` 사용
4. **표 정렬** — 헤더 가운데 / 수치 우측 / 가변 길이 문장·이메일 좌측 / 나머지 가운데
5. **인풋·버튼 높이 34px** 통일
6. **`useQaState`는 검수 전용 배선** — 납품 후 `useState`로 되돌려도 무방
7. 폼은 `FormModal`에 필드 배열만 — 검증은 라벨로 자동 추론

후속 개발자는 **`docs/개발자-가이드.md`** 를 먼저 읽으면 됩니다.

## 9. ⚠️ 검수 완료 후 삭제할 것 — 검수 도구

작업 목록(검수 인덱스 116항목)과 화면 우하단 검수 바는 **클라이언트 검수를 위한 임시 도구**입니다.
검수가 끝나면 아래 한 줄로 관련 코드가 모두 제거됩니다.

```bash
npm run remove-qa            # 제거 실행
npm run remove-qa -- --dry   # 무엇이 바뀌는지 미리보기 (파일은 그대로)
npm run build                # 제거 후 확인
```

**제거되는 것**

| 대상 | 위치 |
|---|---|
| 작업 목록 화면 (116항목) | `src/views/index/` |
| 검수 플로팅 바 | `src/components/common/QaBar.tsx` |
| 검수 프리셋 배선 | `src/lib/qa-state.ts` · `qa-open.ts` · 스토어의 `preset` |
| `useQaState` → `useState` 환원 | 전 화면 16개 파일 |
| 경로·전체 메뉴의 "작업 목록" 진입 버튼 | `Breadcrumb.tsx` · `MegaMenu.tsx` |
| 사용자 메뉴의 개발용 바로가기 3종 | `UserDropdown.tsx` |

제거 후 **로그인하면 대시보드로 착지**하도록 자동 전환됩니다.

**남는 것** — 해시 딥링크(`#screen=&modal=`)와 로그인 진입 게이트는 실서비스에서도 쓰이므로 유지됩니다.

> 검수 전용 파일에는 파일 첫 줄에 같은 안내가 주석으로 달려 있습니다.
