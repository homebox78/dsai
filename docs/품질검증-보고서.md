## 4. 기능 실동작 확인

| 기능 | 확인 내용 |
|---|---|
| 진입 동선 | 접속 → 로그인 → 작업 목록 착지 · 로그아웃 시 로그인으로 복귀 |
| 딥링크 | 로그인 전 `#screen=...` 링크 진입 시 로그인 후 해당 화면 복원 |
| 문서 보기 | 실제 PDF·XLSX·DOCX 12종 렌더 · 페이지 이동 · 시트 탭 |
| 확대·축소 | 실동작 확인 (본문 12.6px → 17.6px) |
| 폼 검증 | 필수·이메일·URL·사업자번호·길이(2~100자) 즉시 표시, 위반 시 제출 차단 |
| 데이터 반영 | 폴더 추가·파일 업로드/삭제·멤버 초대·업무 요청·메시지 전송이 화면에 즉시 반영 |
| OCR→색인 | 업로드 후 처리 상태 전이 연출 |
| 검색·필터·정렬·페이징 | 전 화면 실동작 |

## 6. 검수 도구 제거 안내

작업 목록(116항목)과 검수 바는 **검수용 임시 도구**입니다. 검수가 끝나면 아래 한 줄로 제거됩니다.

```bash
npm run remove-qa
```

자세한 제거 범위는 `docs/산출물-명세서.md` 9장을 참고하세요.

## 7. 목업 범위 안내

본 산출물은 **백엔드·데이터베이스 없이 동작하는 프론트엔드 목업**입니다.

- 로그인은 형식만 갖춘 화면으로, 실제 인증은 수행하지 않습니다
- AI 응답(챗봇·요약·증빙 검색)과 OCR·RAG 처리는 **연출**이며 실제 모델을 호출하지 않습니다
- 화면에서 추가·수정한 데이터는 브라우저 메모리에만 반영되며, **새로고침 시 초기 상태로 돌아갑니다**
- 문서 보기는 예외적으로 **실제 파일**(PDF·XLSX·DOCX 12종)을 렌더링합니다
