# 납품 전 정리 · 제거 대상 목록

납품 패키지에 **들어가면 안 되는 파일**과 **판단이 필요한 파일**을 구분했습니다.
`node scripts/prepare-handover.mjs` 로 이 목록대로 자동 정리한 사본을 만들 수 있습니다.

## 1. 반드시 제거 (개발 부산물 · 용량 · 무관)

| 대상 | 크기 | 이유 | 처리 |

| `dist/` | 28MB | 빌드 산출물. `npm run build` 로 재생성 | 제외 (정적 배포본만 별도 전달) |
| `.playwright-mcp/` | 8.5MB | 자동 검수 중 생성된 스크린샷·콘솔 로그 | **삭제** |
| `userdd.png` | 235KB | 작업 중 남은 임시 스크린샷 | **삭제** |

| `*.log` | — | 개발 서버 로그 | 삭제 |

## 4. 코드 안에 남은 "검수 전용" 배선 (제거는 선택)

납품 후 실서비스로 넘어갈 때 정리하면 되는 항목입니다. **지금 지우면 클라이언트 검수 도구가 사라지므로 검수 완료 후 처리**하세요.

| 대상 | 위치 | 설명 |
|---|---|---|
| 검수 인덱스 화면 | `src/views/index/` | 116항목 작업 목록 |
| 검수 플로팅 바 | `src/components/common/QaBar.tsx` | `window.__qaOpen` 전역 등록 포함 |
| `useQaState` | `src/lib/qa-state.ts` + 각 뷰 | `useState` 로 되돌리면 됨 |
| 프리셋 상태 | `src/stores/app-store.ts` 의 `preset`·`presetSeq`·`applyPreset` | |
| 사용자 드롭다운의 개발 항목 3종 | `UserDropdown.tsx` | 멤버·권한 관리 / 초기 설정 화면 보기 / 로그인 화면 보기 |
| 진입 게이트 | `src/lib/session.ts` | 실제 인증 붙이면 교체 |

## 6. 자동 정리 스크립트

```bash
node scripts/prepare-handover.mjs           # ../amber-front-mockup 에 정리 사본 생성
node scripts/prepare-handover.mjs --with-delivery   # delivery/ 원본도 포함
node scripts/prepare-handover.mjs --out ../납품본   # 출력 위치 지정
```

원본 저장소는 건드리지 않고 **사본만 만듭니다**. 생성 후 사본에서
`npm install && npm run build` 가 통과하는지 한 번 확인하고 전달하세요.
