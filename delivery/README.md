## 파일
| 파일 | 용도 |
|---|---|
| `Amber Document Intelligence.dc.html` | 작업 원본. 편집·수정은 이 파일에서 |
| `Amber Document Intelligence (standalone).html` | 인터넷 없이 더블클릭으로 열리는 단독 실행본(검수·공유용) |
| `support.js` | 원본 실행에 필요한 런타임 (같은 폴더에 함께 있어야 함) |
| `assets/amber-logo.png` | 로고 심볼 |
| `design-system/` | 추출한 디자인 시스템(토큰·컴포넌트·가이드라인·UI 키트) |
| `CLAUDE.md` | 제작 규칙(아이콘·화면 운영 원칙·표기·스택) |

## 확인 방법
1. 파일을 열면 **작업 목록(검수 인덱스)** 이 먼저 나옵니다.
2. 스토리보드 페이지 번호별 **작업 항목**이 그룹·유형(화면/모달/시트/드롭다운/패널/오버레이)으로 정리되어 있고, "열기"를 누르면 해당 레이어가 그 상태 그대로 뜹니다.
3. 우하단 **검수 인덱스 플로팅 바**로 이전/다음 항목을 순서대로 넘겨볼 수 있습니다. (납품 시 제거 대상)
4. 주소창 해시(`#screen=store&modal=upload`)가 상태를 보존하므로 특정 화면 링크 공유가 가능합니다.

# 구현 범위

## 1. 인증 · 초기 셋업
| 항목 | 구현 내용 |
|---|---|
| 로그인 | 좌측 브랜드 패널(파형 배경) + 폼, SSO 진입 |
| 회원가입 | 초대 안내 배너, 비밀번호 강도 미터 4단계 + 규칙 실시간 체크, 약관 동의(전체 동의 연동) |
| 계정 찾기 | 아이디·비밀번호 찾기 + SSO 안내 |
| 2단계 인증 | 6칸 OTP, 남은 시간 카운트다운 + 진행 바, 백업 코드, 30일 신뢰 |
| 초기 셋업 | 조직 → 조직&사업부 → 프로젝트 3단계. 스텝 레일 + 폼 + 우측 계층 트리 실시간 반영, 플랜 카드, 멤버 초대 칩 |

## 2. 앱 셸
- **헤더**: 로고 · 조직명/플랜 · 검색 · AI(✦) · 설정 · 알림 · 도움말 · 프로필
- **경로(breadcrumb)**: 조직 › 조직&사업부 › 프로젝트 › 현재 화면 + 배지(파일 수·RAG 색인) + 우측 액션
- **좌측 메뉴**: 프로젝트 / 협업공간 / 문서 / 에코바디스 / 시스템 5그룹, 배지 카운트, 접으면 아이콘 레일
- **패널 접기·펼치기**: 메뉴 · 파일 목록 · 챗봇 3곳, 경계선 위 원형 핸들로 통일
- **반응형**: 1240px 미만 챗봇 자동 접힘(시트 폴백), 1040px 미만 보조 열 접힘

## 3. 대시보드
상단 요약(오늘 할 일·제출 D-day·기간 필터) · KPI 4종(클릭 시 해당 화면 점프) · 내가 해야 할 일(받은/보낸 탭) · 에코바디스 진행률 + 막힌 문항 · 문서 파이프라인 · 협업공간 활동 · 우측 레일(AI 처리 상태·외부 협업자·최근 활동·스토리지)

## 4. 문서 저장소 (★ 핵심)
| 영역 | 구현 내용 |
|---|---|
| 폴더 트리 | 검색 필터, 폴더 추가 모달, 우클릭 메뉴 |
| 파일 목록 | 정렬·상태 필터, 유형 아이콘, 다중 선택, 우클릭 메뉴 |
| 파일 상세 | AI 요약 숨기기/보기, 상태 배지, 뷰어(확대·페이지 이동·근거 하이라이트), 메타데이터·버전·활동 탭 |
| 문서 작성 | 목차 + 에디터 + AI 어시스턴트, **삽입 위치 드롭다운 7종**(현재 커서/새 문단/선택 문단 아래/선택 영역 교체/문서 끝/제목/표) |
| 챗봇 영역 | 목록 단계 = 폴더 내 파일 찾기 / 상세 단계 = 문서 내용 검색. 근거 클릭 시 해당 페이지로 점프 |
| 모달 | 폴더 추가, 새 파일(doc/hwp/md), 파일 업로드(진행률 + OCR·RAG 토글), 삭제 확인 |

## 5. 협업공간 (채팅 + 업무)
- 룸 목록(검색·필터) / 대화(날짜 구분·읽음·호버 액션·반응) / 우측 업무존(채팅↔Task 탭)
- 대화 내 검색, 고정 메시지 패널, 답장 인용, 멘션 목록 → 담당자 자동 지정
- 첨부 파일 카드 · 업무 요청 카드, 업무 요청 시트, 외부 협업자 초대 모달(만료·권한), Task 미리보기 모달 3탭(미리보기/버전/활동)

## 6. 업무 관리
워크플로 진행 표시(요청됨→진행중→검토대기→완료) · 상태별 목록 · 기한 필터·정렬 · 상세(타임라인·증빙 업로드·코멘트 프리셋) · 우측 실시간 스트림(재요청 방지 이력)

## 7. 에코바디스 (★ 핵심)
| 화면 | 구현 내용 |
|---|---|
| 요약 | 질문항 결과 목록, 진행률(AI 초안·미처리·답변완료 합산), 페이징, 요청한 자료 |
| 문항 처리부 | OCR 문항 수정, 폴더 지정 1회성 AI 증빙 검색(찾음/못찾음 분기), 프로세스 4단계, 답변 + 증빙 확정, 챗봇·Task 탭 |
| 증빙자료 | 문항 ↔ 문서 ↔ 인용 페이지 매핑 테이블, 영역·검증 상태 필터, 커버리지 82%, 확인 필요 알림, 증빙 팩 내보내기 모달(PDF/ZIP/XLSX) |
| 자료요청 | 담당자 자료 요청 → Task 생성 연동 |

## 8. 조직 · 계정 · 시스템
- **조직&사업부 스위처(N)**: 조직 목록 · 크레딧 · 내 프로젝트 · 조직&사업부별 프로젝트 트리 · 생성/초대/로그아웃
- **멤버 관리**: 검색·필터, 다중 선택 일괄 액션, 권한 드롭다운, 권한 그룹 3종
- **시스템**: 조직&사업부 / 채널 관리 / 권한 그룹 탭별 테이블
- **설정 5영역**: 내 계정 · 보안·로그인(2FA·로그인 기록) · 조직&사업부 · AI·색인 · 알림
- **전체 메뉴 오버레이**: 메뉴 검색, 바로가기 5종, 메뉴 그룹 6개, 우측 패널(할 일·최근 본 화면·현황)

## 9. 공통 규칙
- 아이콘 전량 **Google Material Symbols** (직접 그린 SVG·이모지·문자 글리프 없음)
- 네이티브 `select` 미사용 — 전부 커스텀 드롭다운. **트리거와 드롭다운 동일 폭**, 스크롤 영역 하단 행은 **위로 열림**(잘림 방지)
- 카드 대신 **라인(divider)** 기반 레이아웃, 테이블 행 높이 11px/18px 통일
- 모달·시트 헤더/푸터/버튼 규격 통일, 푸터 버튼 5:5
- 딥블루 헤더 위 입력의 placeholder는 흰색 알파로 표시(가독성)
- 패널 접기 핸들은 경계 안쪽에 고정해 우측 끝에서 잘리지 않음
- 페이지 이동 없이 한 화면 위 레이어(모달 20여 종 / 시트 4종 / 드롭다운 7종)로 동작
- 단축키: `G`+키 이동, `U`/`N`/`R`, `Esc`, `[` `]`, `⌘K`, `?`

## 범위 제외 · 남은 것
- 도움말 상세 페이지 4종(사용가이드·도움말·약관·고객센터) → 드롭다운까지만 구현, 상세는 클라이언트(Aiden) 제작
- 문서 작성 **목차 편집 페이지**(p44) → 클라이언트 제작
- 백엔드·DB·실제 AI 연동 없음. AI 응답·OCR/RAG 진행률은 시뮬레이션 연출
- 데스크톱 기준(1240px 이상 권장). 모바일 대응은 범위 외
- 검수 인덱스·플로팅 바는 검수 전용 → 실제 개발 시 제거
