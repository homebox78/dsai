# Amber Document Intelligence · Front Office 목업 (인수 안내)

기준 문서: 「Amber UIX 설계서 V0.1」 Storyboard(front Office) V1.1 (63p)

## 파일
| 파일 | 용도 |
|---|---|
| `Amber Document Intelligence.dc.html` | 작업 원본. 편집·수정은 이 파일에서 |
| `dist/Amber Document Intelligence (standalone).html` | 오프라인 단독 실행본. 더블클릭하면 브라우저에서 바로 열림 (인터넷 불필요) |
| `CLAUDE.md` | 제작 규칙(아이콘·화면 운영 원칙·표기·스택) |

## 확인 방법
1. standalone 파일을 열면 **작업 목록(검수 인덱스)** 이 먼저 나옵니다.
2. 스토리보드 페이지 번호별로 **95개 항목** 이 그룹·유형(화면/모달/시트/드롭다운/패널/오버레이)으로 정리되어 있고, "열기"를 누르면 해당 레이어가 바로 그 상태로 뜹니다.
3. 화면 우하단 **검수 인덱스 플로팅 바**로 이전/다음 항목을 순서대로 넘겨볼 수 있습니다. (납품 시 제거 대상)
4. 주소창 해시(`#screen=store&modal=upload`)가 상태를 보존하므로 특정 화면 링크 공유가 가능합니다.

## 구현 범위
- 인증 4종(로그인·회원가입·계정찾기·2FA), 초기 셋업 3단계(스텝 레일 + 데이터 출력 패널)
- 앱 셸: 헤더(N 스위처·검색·AI·설정·알림·도움말·프로필) / breadcrumb / 좌측 메뉴 / 컨텐츠 / 챗봇 — 패널 3종 경계 핸들로 접기·펼치기
- 대시보드, 문서 저장소(4분할·파일 상세·작성기·AI 삽입 7종), 채팅+업무존, 업무 관리, 에코바디스(요약·문항 처리부·증빙자료), 멤버·시스템, 설정 5영역, 전체 메뉴 오버레이
- 모달 20여 종 / 시트 4종 / 드롭다운 7종 — 전부 한 화면 위 레이어로 동작
- 단축키: `G`+키 이동, `U`/`N`/`R`, `Esc`, `[` `]`, `⌘K`, `?`
