# Amber Document Intelligence — Design System

**Amber Document Intelligence** (EvolvAiLab · *Private AI for Enterprise Knowledge*) 의 프론트 오피스 디자인 시스템.
기업 내부 문서를 OCR·RAG로 색인하고, 키워드가 아닌 의미 추론으로 근거를 찾아주는 **사내 전용 AI 문서 지식 콘솔**의 UI 언어를 정의한다.

## 제품 컨텍스트

- 데이터 계층: **조직 → 조직&사업부 → 프로젝트** → (문서 저장소 · 파일 · 채팅방 · 업무 · 에코바디스 · AI 로그)
- 단일 앱 셸 제품이다. 라우트는 인증 / 초기 셋업 / 앱 셸 3개 수준이며, 그 안에서 **컨텐츠 영역 교체 + 모달·시트·패널 펼치기**로 모든 동선이 돈다.
- 주 사용자는 ESG·준법·구매 실무자와 관리자. 200~300문항 규모의 에코바디스 대응이 핵심 업무 흐름이다.

## CONTENT FUNDAMENTALS

**언어** — 전 화면 한국어. 영문은 고유명사(ENTERPRISE, RAG, OCR, TASK-139)와 단위(files, stores, channels)에만 남긴다.

**용어 고정**
- "워크스페이스" → **조직&사업부**
- "Store" → **문서 저장소**, "Task" → **업무**, "EcoVadis" → **에코바디스**
- 계층 표기는 항상 `조직 › 조직&사업부 › 프로젝트` 순서

**톤** — 담담한 실무 문서체. 감탄사·마케팅 수사·이모지를 쓰지 않는다.
- 서술형 안내는 `~합니다` 체: "업로드 후 OCR·RAG 색인을 실행합니다"
- 버튼은 동사형 명령: "업로드 시작", "요청 보내기", "완료 처리", "증빙 팩 내보내기"
- 라벨은 명사구: "연결된 증빙 문서", "유효기한", "처리 이력"
- 빈 상태·경고는 원인 + 다음 행동을 같이 준다: "문항에 연결된 문서가 없습니다. 담당자에게 자료 요청을 보내세요."

**1인칭/2인칭** — 사용자 소유물은 "내 프로젝트", "내가 해야 할 일"처럼 **내**. 지시문은 주어 없이 동작만: "폴더를 선택하세요". "당신"은 쓰지 않는다.

**숫자·단위** — 천단위 콤마(1,284), 진행률은 정수 %(82%), 기한은 `~07.26` / `D-18`, 문항은 `152 / 300문항`, 파일 크기는 `2.4MB`.

**금지** — 이모지, 느낌표, "AI가 똑똑하게", "손쉽게" 같은 과장, 영문 UI 라벨(Upload files 등), 물음표 없는 의문형 버튼.

## VISUAL FOUNDATIONS

### 색
- **딥블루 헤더가 브랜드의 얼굴**이다. `--blue-700 #1750d8` 이 프라이머리이고 hover는 `#1345bd`. 헤더 위 컨트롤은 흰색 알파(.10 / hover .20 / border .24)만 쓴다 — 슬레이트 톤을 얹지 않는다.
- 본문은 **블루-그레이 슬레이트** 단일 램프. 텍스트 `#0f172a` → `#64748b` → `#94a3b8`, 라인 `#e2e8f0`(구조) / `#f1f5f9`(행), 캔버스 `#f8fafc`, 사이드 메뉴 `#fafbfc`.
- 초록은 **완료·준비됨 신호에만** 절제해서 쓴다(RAG 색인 완료, 검증완료, 커버리지 수치). 배경 채움으로 넓게 쓰지 않는다.
- 상태 색 매핑은 고정: 완료=green, 검토대기=amber, 만료임박=orange, 미연결·기한초과=red, 중립=slate.
- 그라디언트는 인증 화면 배경 파형에만 존재한다. UI 표면에는 그라디언트가 없다.

### 타입
- **Pretendard Variable** 단일 서체(한글·영문 공용) + 식별자용 시스템 모노.
- 스케일은 목업 실측값을 그대로 쓴다(13.6px 본문, 12.6px 보조, 12.1px 라벨, 11.2px 섹션 라벨…). 4px 그리드로 스냅하지 않는다.
- weight는 400/600/700/800 네 단계. 섹션 헤더·KPI·배지는 800, 목록 이름은 600.
- 트래킹: 큰 제목은 음수(-.02 ~ -.03em), 대문자·섹션 라벨은 +.05em.
- line-height 1.7 기본. 제목 아래 보조 텍스트는 4px 간격.

### 레이아웃
- 형태1: 헤더(52) / 경로(44) / [메뉴 234 │ 서브목록 264 │ 컨텐츠 │ 챗봇 330] 4단. 형태2는 서브목록 없는 3단.
- **영역 구분은 카드가 아니라 라인.** 패널 헤더는 44px 고정, 목록·테이블 행은 상하 11px / 좌우 18px 고정.
- 패널 접기/펴기는 경계선 위에 떠 있는 **22px 원형 핸들**(top 96px)로만 한다. 헤더 햄버거·하단 바 없음.
- 좁은 폭(1240/1040px)에서는 챗봇 → 시트, 서브목록·업무존 → 자동 접힘. 컨텐츠 열에는 최소 폭을 걸어 0으로 붕괴하지 않게 한다.

### 표면 · 보더 · 라운딩
- 카드에 그림자를 쓰지 않는다. 그림자는 **떠 있는 레이어 4종**뿐: dropdown `0 14px 36px/.14`, modal `0 24px 60px/.22`, sheet `-18px 0 48px/.16`, handle `0 1px 3px/.12`.
- 라운딩은 요소별 고정: 코드 배지 4 · 아이콘버튼·입력 6 · 보조버튼·칩 7 · 프라이머리·카드 8 · 드롭다운·패널 10 · 모달 12 · 배지·토글 pill.
- 투명도·블러는 딤(`rgba(15,23,42,.38)`)과 헤더 위 알파에만. backdrop-filter는 쓰지 않는다.

### 상태
- hover = `--slate-100` 채움 (또는 헤더 위 알파 .20). 텍스트 색은 바꾸지 않는다.
- selected = `--blue-50` + **좌측 2px 블루 라인** + 라벨 700/블루.
- focus = 블루 보더 + `0 0 0 3px rgba(23,80,216,.12)` 링. 네이티브 outline 금지.
- disabled = opacity .45. press 상태에 스케일·바운스를 주지 않는다.

### 모션
- `.12s` hover·포커스·드롭다운(4px 위에서 페이드인) / `.16s` 패널 width·시트 슬라이드 / `.25s` 진행률 바.
- 이징은 전 시스템 `ease` 하나. 스프링·바운스·회전·패럴랙스 없음.
- 인증 화면 좌측 파형만 예외적으로 느린 루프 애니메이션을 갖는다(투명도 .42, 2줄).

### 이미지
- 제품 UI에 사진·일러스트를 쓰지 않는다. 시각 요소는 아이콘·라인·진행 바·확장자 타일뿐.
- 문서 뷰어는 흰 종이 위 텍스트 재현으로 표현한다(그림자 없는 1px 보더).

## ICONOGRAPHY

- **Google Material Symbols Rounded 전용.** CDN에서 로드하며(`tokens/fonts.css`), 다른 아이콘 세트(lucide 등) 혼용 금지.
- 인라인 SVG, 이모지, 문자 글리프(‹ › ✕ ▼ ⋮)를 아이콘으로 쓰지 않는다 — 전부 글리프명으로 대체한다.
- 크기: 사이드 메뉴 18.4px · 헤더·툴바 17~18px · 인라인 14~16px · 빈 상태 26px+.
- 도메인 매핑(고정): 대시보드 `space_dashboard` · 멤버 `group` · 채팅 `forum` · 업무 `task_alt` · 문서 저장소 `folder_open` · 문서 `description` · 요약 `monitoring` · 문항 `checklist` · 증빙자료 `verified_user` · 자료요청 `move_to_inbox` · 설정 `settings` · AI `auto_awesome`.
- 로고는 `assets/logo/amber-logo.png` 하나. 딥블루 배경에서는 단독, 흰 배경에서는 블루 배지 안에 넣는다. **다른 마크를 새로 그리지 않는다.**

**의도적 추가 (Intentional additions)**
- `PanelToggleHandle` — 목업에서는 인라인 마크업이지만 세 곳(메뉴·서브목록·챗봇)에서 동일하게 반복되므로 컴포넌트로 승격했다.
- `Select` — 목업의 커스텀 드롭다운을 컴포넌트화. 네이티브 `<select>` 금지 규칙을 코드로 강제하기 위함.

### UI 키트

`ui_kits/console/index.html` — 클릭 가능한 콘솔 셸. 메뉴로 4화면(대시보드 · 문서 저장소 · 업무 관리 · 증빙자료)을 갈아 끼우고, 경로 영역 버튼으로 업로드·새 문서 모달과 업무 요청 시트를 연다.

## 사용 규칙 (요약)

1. 새 화면을 만들지 말고 **셸 안에서 레이어를 연다** — 모달 / 시트 / 패널 펼치기.
2. 색·간격·라운딩은 토큰만 쓴다. hex 하드코딩 금지.
3. 아이콘은 Material Symbols Rounded 글리프명.
4. 영역 구분은 라인. 카드 중첩·그림자 카드 금지.
5. 프라이머리 버튼은 화면·레이어당 1개.
6. 모달·시트 푸터 버튼은 5:5 동일 폭.
7. 전 화면 한국어, "조직&사업부" 표기 유지.
